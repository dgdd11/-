## Оновлення матеріалів через Git

```bash
git clone https://github.com/dgdd11/-.git apz
cd apz
# Додати файли наступної роботи до pr3.
git add pr3
git commit -m "Add practical work 3"

```

Для відправлення змін потрібна авторизація власника або іншого користувача з правом запису. Звичайний відвідувач публічного репозиторію може читати й завантажувати матеріали, але не змінювати їх у гілці власника.

## Контрольні питання

1. **Що таке контроль версій Git?** Система, яка зберігає історію змін файлів і дозволяє порівнювати та відновлювати попередні стани.
2. **Що таке репозиторій?** Сховище проєкту з історією комітів, гілками та іншими даними Git. У локальному репозиторії ці дані містяться в каталозі `.git`.
3. **Які переваги Git?** Історія змін, відновлення станів, робота в гілках, поєднання змін і спільна робота з іншими розробниками.
4. **Як створити репозиторій?** Локально командою `git init`; на GitHub - через New repository. Після цього файли додають, комітять і передають у віддалений репозиторій.
5. **Чи можна надати доступ іншій людині?** Так. Публічний репозиторій доступний для читання всім. До приватного можна запросити користувача з відповідними правами.
